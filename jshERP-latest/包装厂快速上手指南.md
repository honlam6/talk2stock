# 华夏ERP（jshERP）包装材料厂 — 业务员快速上手指南

> 适用对象：没用过 ERP、要从管家婆换过来的厂里业务员
> 目标：不用懂原理，照着点就能把每天的业务录进系统
> 系统地址：http://localhost:8080/   账号：jsh  密码：123456（首次登录要填验证码）

────────────────────────────────────────
一、先建立一个直觉：ERP 每天就干 4 件事
────────────────────────────────────────
1. 进货 —— 供应商把货送来，你录"采购入库"
2. 卖货 —— 客户要货，你录"销售出库"
3. 收钱/付钱 —— 银行流水和 ERP 对账，用"收款/付款"
4. 查账 —— 随时看"现在仓库有什么、欠谁钱、谁欠我钱"

记住一句话：**每做一笔业务，就录一张单。录完系统自动帮你算库存、算应收应付。你不用自己加减。**

────────────────────────────────────────
二、第一次登录要做的 3 件准备（管理员做，只需一次）
────────────────────────────────────────
1. 基础资料 → 商品信息：把你们厂卖/买的"东西"都建好（纸箱、薄膜…）
2. 基础资料 → 往来单位：把供应商、客户都建好
3. 系统管理 → 仓库管理：原料仓、成品仓建好（已帮你建了）

*这些我们已帮你预置了一批包装厂示例数据，登录后就能看到，先照着学。*

────────────────────────────────────────
三、最日常的两笔操作（照着点）
────────────────────────────────────────

【场景A：供应商送货来了 → 录采购入库】
左侧菜单：采购管理 → 采购入库 → 点右上角"新增"
- 单据日期：默认今天
- 供应商：选"玖龙纸业(东莞)有限公司"
- 仓库：选"原料仓"
- 点"增行"，商品选"牛皮纸卷 120g"，数量填 100，单价填 800
- 付款账户：选"中国银行对公账户"，本次付款填 80000
- 点"保存并审核"
→ 系统自动：原料仓牛皮纸 +100卷，银行账户 −80000

【场景B：客户要货了 → 录销售出库】
左侧菜单：销售管理 → 销售出库 → 点右上角"新增"
- 客户：选"顺丰包装制品有限公司"
- 仓库：选"成品仓"
- 点"增行"，商品选"五层瓦楞纸箱"，数量填 200，单价填 5
- 收款账户：选"现金账户"，本次收款填 1000（其余挂应收）
- 点"保存并审核"
→ 系统自动：成品仓纸箱 −200个，现金 +1000，顺丰还欠你 0（按实际填）

────────────────────────────────────────
四、录完去哪看结果（让老板放心）
────────────────────────────────────────
- 仓储管理 → 库存查询：看现在每个仓库剩多少货
- 财务管理 → 收款单/付款单：看钱进出
- 报表查询 → 进出库明细：每一笔货的来龙去脉
- 统计 → 客户对账/供应商对账：谁欠谁多少钱

────────────────────────────────────────
五、和管家婆最大的不同（给老板/业务员的心理准备）
────────────────────────────────────────
1. 管家婆很多操作是"直接改数字"，jshERP 是"每笔业务一张单"——
   好处：每笔都有据可查，错了能追；坏处：要养成"先录单再做事"的习惯。
2. 单据分"保存"和"审核"两步。保存=草稿，审核=生效（库存才变）。
   新手最容易犯的错：只保存不审核，然后发现库存没变 → 去点"审核"。
3. 角色分工（建议在系统里分账号）：
   - 录单员：只能录采购入库/销售出库
   - 审核员：审核单据（避免一人又录又审）
   - 老板：看报表

────────────────────────────────────────
六、常见问题
────────────────────────────────────────
Q：库存没变？ → 单据只"保存"没"审核"。去列表里点"审核"。
Q：找不到商品？ → 去基础资料→商品信息里先建。
Q：客户/供应商选不到？ → 去基础资料→往来单位里先建。
Q：登录提示验证码？ → 正常，看登录框旁边的图片输进去。
Q：录错了怎么办？ → 未审核可直接删；已审核要先"反审核"再改。
